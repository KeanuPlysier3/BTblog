## Logistic concerns
- We should tie the wand with a string so the kids won't take it.
- LED lights on the floor might be a bit messy and become obstacles for visitors to walk around.

## Concept concerns
- With the riddles about the characters, how would we prevent favoring specific authors?
- Our target audience unclear right now, we need to specify that the target audience is families, but groups of friends are also welcome to play.
- The game should mention the age limit.

## Presentation concern
- Our pitch right now is too long, we should exclude the technical side for now and see if the client is happy with the concept.

## Conclusion
The feedback we received was mostly targeted towards our actual presentation. The only thing we actually need to fine tune is how to implement the wands in a robust way, that doesn’t require a lot of cables. We also need to check in with the client how and which characters we can use so it doesn’t look like we’re favoring a certain author.
